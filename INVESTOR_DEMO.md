# 🚀 MY Internship Platform - Quick Start Guide for Investors

## **ONE-COMMAND STARTUP** ⚡

### **For Mac/Linux:**
```bash
chmod +x start.sh
./start.sh
```

### **For Windows:**
```bash
start.bat
```

**That's it! The app opens automatically in your browser!** 🎉

---

## **Manual Setup (if scripts don't work)**

### **1. Install Prerequisites**
- Node.js 18+ ([Download](https://nodejs.org))
- Git ([Download](https://git-scm.com))

### **2. Clone & Navigate**
```bash
git clone https://github.com/imtermship/my-internship-platform.git
cd my-internship-platform
```

### **3. Start Backend**
```bash
cd backend
npm install
npm run dev
```

**Backend runs on:** `http://localhost:5000`

### **4. Start Frontend (in a NEW terminal)**
```bash
cd frontend
npm install
npm run dev
```

**Frontend runs on:** `http://localhost:3000`

## **🚨 COMMON ISSUES & FIXES**

### **Port Already in Use**
```bash
# Kill process on port 3000 (frontend)
lsof -i :3000
kill -9 <PID>

# Kill process on port 5000 (backend)
lsof -i :5000
kill -9 <PID>
```

### **npm install fails**
```bash
# Clear cache and retry
npm cache clean --force
npm install
```

### **Frontend doesn't load**
- Make sure backend is running first (wait 5 seconds)
- Clear browser cache (Ctrl+Shift+Delete)
- Try incognito mode
