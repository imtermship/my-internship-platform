# MY - Internship Platform 🎓

A modern platform connecting **students**, **employers**, and **educational institutions** around internships.

## 🎯 Core Philosophy
**Complexity for the system. Simplicity for the user.**

## ✨ Features
- 📱 **Student Portal** - Discover, apply, and track internships
- 🏢 **Company Dashboard** - Post roles, review applications, manage internships
- 🏫 **Institution Dashboard** - Monitor placements and access records
- ✅ **Acceptance Verification** - PDF + unique code + QR verification
- 📄 **Auto-generated Documents** - Acceptance PDF and completion records
- 🔔 **Smart Notifications** - Automatic event-driven notifications
- 🔐 **Role-based Access Control** - Secure, isolated user experiences

## 🛠 Tech Stack
- **Frontend:** Next.js 14 + React 18 + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Authentication:** JWT

## 📁 Project Structure
```
my-internship-platform/
├── backend/          # Express API server
├── frontend/         # Next.js client application
└── docs/            # Documentation
```

## 🚀 Quick Start
Frontend: `cd frontend && npm install && npm run dev`
Backend: `cd backend && npm install && npm run dev`

Visit `http://localhost:3000`
